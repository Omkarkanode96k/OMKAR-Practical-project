# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a beginner-friendly website that helps a teacher mark students as Present or Absent and view an attendance summary.

## Objectives
- Display a list of students.
- Mark each student Present or Absent.
- Count present and absent students.
- Calculate the attendance percentage.

## Technologies Used
- HTML — website structure
- CSS — colours and design
- JavaScript — attendance functions and calculations
- Git and GitHub — version control and collaboration

## Files
- `index.html` — main web page
- `style.css` — design and layout
- `script.js` — attendance functionality

## How to Run
1. Download the project folder.
2. Open `index.html` in a web browser.
3. Select Present or Absent for each student.
4. Click **Update Summary** to see the totals.
